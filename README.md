# Déclic

*Le déclic*: the moment a habit finally clicks.

An Android habit tracker for all your habits (skincare, bedtime, a 10 km run,
gym sessions) that can also block distracting apps until a habit is done. For
habits tied to a place, you prove it by scanning an NFC tag placed where the
habit happens, like a sticker next to your skincare.

**Status:** planning. No code yet. The thinking comes first and is documented as it happens.
